## Featured projects

### 1. [GridSnare](https://github.com/Naveenbtnk/GridSnare)

A cybersecurity and ICS/SCADA security platform combining deception, protocol-aware detection, and evidence-backed testing.

- Monitors **Modbus TCP** and **IEC 61850 GOOSE** activity
- Uses deception and honeypots to surface suspicious behavior
- Provides detection/correlation logic, a dashboard, Docker-based deployment, and test evidence

### 2. [RemedyGraph](https://github.com/Naveenbtnk/RemedyGraph)

A security engineering application for verifying incident remediation rather than treating remediation as a checklist.

- Built with **FastAPI**, **React**, and **SQLite**
- Includes CI and automated testing for evidence-based verification
- Includes a live **Vercel** demo linked from the repository

### 3. [Java-RAG](https://github.com/Naveenbtnk/Java-RAG)

A retrieval-augmented generation application built as a modern Java backend.

- Uses **Java 17+**, **Spring Boot**, **LangChain4j**, and **Mistral AI**
- Stores and retrieves embeddings with **PostgreSQL / PGVector**
- Supports Docker deployment and includes a live **Render** demo linked from the repository

### 4. [Virtual-Assistant-For-MultiTask-Automation](https://github.com/Naveenbtnk/Virtual-Assistant-For-MultiTask-Automation)

A Python automation assistant that combines speech, language processing, email workflows, and machine learning.

- Built with **Python**, **Flask**, and **Whisper**
- Automates email through **SMTP/IMAP**
- Uses **TensorFlow/ANN**, **NLTK**, **spaCy**, and **gTTS**

### 5. [AI-Email-Generator](https://github.com/Naveenbtnk/AI-Email-Generator)

A Java service for generating email content through the Gemini API.

- Built with **Java 23** and **Spring Boot 4**
- Integrates Gemini using **WebClient** and **Jackson**
- Uses **Lombok** and **Maven** for maintainable development and builds
